Work

A few of my favorite things I've built.

audio + video · in progress

radiostar-killer

An automatic beat-synced music video generator. Real-time beat detection and video composition run entirely client-side via WebAssembly and the WebCodecs API. No server, no upload. Actively evolving.

audio plugin · JUCE / Rust

pitchzazz

Real-time pitch correction ("autotune") with a Rust CLI and a C++/JUCE plugin sharing the same DSP design. Three pitch-shift engines hot-swap live with zero audio dropout. The linked notebook walks every mechanism down to the source line.

voice + AI · iOS

noogat.app

Voice notes that organize themselves. Say "Hey Siri, I have a Noogat" and your thought is saved instantly, no unlocking or app switching. AI auto-tagging and semantic search so you can always find it again.

open source · Rust crates

rust crates

Audio and video utility crates for Rust, published on crates.io. Starting with beat-track-rs, a tempo and beat-position estimator using the Ellis (2007) dynamic-programming algorithm — more on the way.
